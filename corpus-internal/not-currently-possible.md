---
title: "Things Oxford Abstracts does not currently support"
internal: true
last_reviewed: 2026-07-29
---

Confirmed limitations. Answer these plainly — a clear "no" is more useful than a
workaround that doesn't exist.

- **Changing fonts** — you cannot change fonts on Oxford Abstracts software.
- **Visa / invitation letters** — there is no feature to generate visa support letters.
  Submitters asking about this should contact their event administrator.
- **DOIs** — Digital Object Identifiers are not supported.
- **Duplicating or cloning a question** — not possible.
- **Importing sessions in bulk / via CSV** — not possible at this time.
- **Italics on the review form** — not available.
- **Changing the "Get tickets" button wording** — the button text cannot be changed.
- **Hyperlinks in a ticket description** — not currently possible, but planned.
- **Checking for duplicate IDs in the programme** — not supported. Workaround:
  Conference > Program > Sessions > Submission IDs.
- **Group tickets** — you cannot buy a "group" ticket, but an attendee can buy multiple
  tickets and name the other ticket holders on the registration form.
- **A mobile app** — there is no Oxford Abstracts app.
- **Re-running auto-assign for some submissions only** — re-running auto-assign
  re-assigns all submissions.
- **Committee members building the programme** — only admin users can create sessions
  and allocate presentations to them.
- **Multiple users editing the same abstract** — only the person who submitted it can edit it.
- **Admins changing a reviewer's email** — reviewers must change it themselves from their
  own account.
- **Admins changing an attendee's name** — attendees do this from their profile page.
- **Admins changing a submitter's email address** — only the submitter can, from
  My Profile.
- **Authors and affiliations on the decisions table** — that data appears only on the
  Submissions table accordion rows, not the Decisions page.
