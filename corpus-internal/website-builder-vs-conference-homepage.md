Website builder versus conference homepage, difference between the two sites, redirect
the old homepage to my new website, hide the conference homepage, own domain, multiple
pages, which one do exhibitors and networking live on, virtual.oxfordabstracts.com.

Distilled from support replies in the year to July 2026. Organisers who build a site
with the website builder routinely end up with two public addresses and ask which one
attendees should use.

**They are two different things.**

- **The website builder** produces a public marketing site. It can use your own domain
  and can have as many pages as you like. It is meant to be the public face of the
  conference before and around the event.
- **The conference homepage** sits on an Oxford Abstracts address and is organised as
  tabs rather than pages. It is what an attendee lands on when they log in to the
  event portal, and it is where the conference platform features live — the programme,
  the poster gallery, exhibitor booths and networking.

**Redirecting one to the other is not possible.** The original conference homepage
cannot be pointed at a website-builder site. What you can do instead is **hide** the
conference homepage, so only the built site is public, and let attendees reach the
programme and platform features by logging in once the conference starts.

**So which do you need?** If the question is "I want a proper website with my own
domain", that is the website builder. If it is "I want exhibitor booths, networking or
the poster gallery", those are conference platform features on the Professional
package and are reached through the event portal, not the built site. Wanting both is
normal and does not mean anything is set up wrongly.
