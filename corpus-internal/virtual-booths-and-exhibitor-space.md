Virtual booth, virtual booths, exhibitor booth, sponsor booth, exhibition stand,
exhibitor space, where do I set up booths, can we have virtual exhibitors.

Exhibitor space is a **Professional Conference** feature. Setting it up is covered in
[Exhibitor space admin set up](/08-conference-platform/professional-conference-exhibitor-space-admin-set-up),
and the exhibitor's own side is in
[For attendees and exhibitors](/14-for-attendees-exhibitors/).

This note exists because "virtual booth" is what people type and it was reaching nothing.
The existing exhibitor note, [[exhibitor-booths]], is about fixing a booth once it exists
— the wrong email or the wrong name showing — and its first lines are all about that, so
the router never matched it to somebody asking what booths are or where to find them.
Keep the two separate: this one is "where is it", that one is "it is broken".
