---
title: "Where do I find my event ID?"
audience: organisers
plan: all plans (including free Basic)
last_reviewed: 2026-08-03
---

Your event ID is the number in the address bar while you are signed in and inside
the event. Look at the URL for `/events/` and take the number straight after it:
in `app.oxfordabstracts.com/admin/events/528/app/...` the event ID is **528**.

It is there on every page inside the event, so any screen will do — the dashboard,
the registrations table, the emails screen. Support often ask for it because it is
the fastest way to be certain which event is being discussed, particularly when an
account runs several with similar names or the same event across multiple years.
