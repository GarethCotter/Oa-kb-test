Exhibitor booth wrong email, change the exhibitor contact, wrong name showing on a
booth, exhibitor cannot access their booth, exhibitor representative name incorrect,
sponsor booth setup.

Exhibitor space is a Professional Conference feature. Distilled from support replies
in the year to July 2026.

- **Changing the email address linked to a booth:** on the event dashboard's
  **Exhibitors** page, click into the row and change the email. The new address then
  has access to set the booth up, and the old one loses it. Organisers assume this
  needs support; it does not.
- **A wrong name appearing against a booth** is usually the display name on the
  account behind that email address, not a booth setting — the exhibitor set it when
  they registered, and it follows them. The person changes it from their own profile.
  Where the account itself is wrong, support can delete it so they can register again,
  but check with the exhibitor first: anything else attached to that account goes too.
- **Booth images:** there are recommended dimensions for picture uploads; point people
  at the guide rather than letting them guess, because a badly sized image is the
  commonest complaint after access.
