- **Attendees reach the conference homepage** by logging into your event portal — it's the
  first page they land on.
- **Adding a link inside a programme session:** Program builder → open the session →
  Add a description → Insert link icon → paste your link.
- **Committee members cannot build the programme** — admin users only.
