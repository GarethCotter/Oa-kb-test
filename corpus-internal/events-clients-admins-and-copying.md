Create a new event, next year's conference, copy a previous event, clone an event,
cannot see the new event option, client admin, event admin, super admin, past events
missing, reuse last year's event, organisation name on invoices.

Distilled from around 20 support tickets in the year to July 2026.

**Creating events needs client admin rights.** If a dashboard only offers submitting
or reviewing, the account does not have them. Client admins create events themselves
from the client's new-event page — they do not need to ask support.

**Copying is the normal way to start a new year.** Creating a new event offers a copy
of a previous one, bringing across submission and review forms, email templates and
reviewers. Points that catch people out:

- **Free events cannot be copied** and have to be built from the default questions.
- **Check you are under the right client.** A duplicate client account leaves you
  copying an unused event with only the default form.
- **Copying brings no data** — submissions cannot be moved between events.
- Old sessions, dates, tracks and column names come across too, and are cleared from
  the programme builder Settings menus, sessions individually via the trash icon.

**A past event cannot be reopened and reused for a new year.** Pricing is per
conference, so a new setup is needed. The new event carries a "pay for event" link
which generates the invoice and grants access straight away so work can begin.

**Who sees what:**

- **Client (master) admins** see every event under the organisation.
- **Event admins** see only their own event, not others on the same client account.
- **Super admins** do not appear in an event's admin list because they have access to
  everything; they are managed from the client dashboard.
- Your events may sit under **more than one client account** — if past events seem
  missing, switch client accounts.

Client admins are added and removed on the client admins page, event admins on the
event's admin users page. Support cannot add an admin without approval from an
existing admin.

**Running admin and submitter roles on one account does not work** — you cannot switch
an admin account into the submitter view. Use a second address, or edit the submission
as an admin in the table.

**The organisation name on the account and invoices** is edited on the client edit
page.

**The event abbreviation cannot contain special characters** — they break merge
fields.
