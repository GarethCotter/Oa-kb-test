Event admins, add an admin, invite new program users, inviting new users, give someone
access to my event, remove myself from event, remove a user, take someone off the event,
who can add administrators.

Access to an event is managed from **Event dashboard → Event setup → Users**, which is
where you view, add and remove the people who can get into an event. See
[Manage users](/01-getting-started/manage-users) for the steps.

The distinction that causes most of the confusion:

- **Account Administrator** — access to *every* event in the account. Set up by Oxford
  Abstracts in the first instance; once an account exists, account admins can add more
  account admins.
- **Event Administrator** — access to *specific* events only, and which events is decided
  by the Account Administrator.

So "I want to give a colleague access" has two different answers depending on whether
they need one event or all of them, and only an Account Administrator can grant the
second. Full list of roles in
[Different types of users in the system](/01-getting-started/different-types-of-users-in-the-system).

**Removing yourself** is the same screen — you remove your own row as you would anyone
else's. Warn them of the obvious: if they are the only administrator on the event, they
should add somebody else before removing themselves, or nobody can get back in.
