You do not have to open submissions one at a time. Everything comes down in a single zipped folder from Reports and downloads — the trick is knowing which download gives you what.#

Go to Event dashboard → Abstract Management → Reports & Downloads.

Each submission as its own document#

Choose Abstracts as individual files. You get a zipped folder containing one document per submission, which is what you want for circulating papers to a committee or archiving the set.

Both Word and PDF are offered. The export builds in the background and can sit on a percentage for a minute or more before finishing — let it run rather than starting again. If one format fails repeatedly, try the other, and try a different browser before assuming the data is at fault.

The files your submitters uploaded#

The individual-file downloads contain the text of a submission. Where a submitter attached something to a file upload question — a paper, a poster, a spreadsheet, a video — the document shows a link rather than the file itself.

To get the actual files, use the question response folders on the same page. Each file upload question has its own folder, and you download it as a zip. See Other reports.

Everything in one document#

For a single book containing every submission, use an abstract book instead — see Abstract books.

Two things that surprise people#

Fields go missing when they aren't ticked for the book. Each question on the submission form has an in abstract book setting, and if it is off, that field simply will not appear in the download. Keywords are the usual casualty.

On a multi-stage event this is set per stage. A field ticked for your abstract stage is not automatically ticked for your poster stage, which is why a download can contain a field for some submissions and not others.

Author names cannot be removed from an abstract book. If you need submissions without author details for blind reviewing, do it through the reviewing side of the system rather than by exporting — see Controlling what the reviewer can see.

If a download will not complete#

If an export fails on the same submission every time, one of the attached files may have uploaded incompletely — the symptom is that nobody, including you, can open that particular file. Ask the submitter to upload it again, and if it still fails contact support with the submission number.
