# Networking for attendees

## Networking allows attendees to create name tags so that they can connect and chat with each other. This feature is only available in the Professional Conference package.

The guidance below is for event administrators/ organisers. If you are an end user (eg. submitter, reviewer, delegate etc), please click [here](https://oxfordabstracts.com/resources/contact-support/).

NB: Delegates can only use chat if they have set up a [name badge](/08-conference-platform/networking-for-attendees.html#NB).

[Skip to written instructions.](#TEX)

When attendees sign in, they can create badges as shown below, with optional data such as email address, interests, social media profiles and roles.

![Attendees](/assets/img/attendees-7039c252.webp)

Go to **Event dashboard → Conference** → **Configure →** **Networking**

This will open the Networking panel. In the upper part of the panel you will see:

1)  [Advanced / Virtual Conference Program - Controlling access](/08-conference-platform/controlling-access-to-the-programme)

2) [Setting up name badges](#NB) (below)

3), 4) and 5) the chat settings   [Advanced / Virtual Program - Chat feature](/08-conference-platform/the-chat-feature.html)

![](/assets/img/undefined-oct-14-2021-02-54-18-49-pm-e3dced85.webp)

#### Setting up name badges

The first step is to enable name badges, which is done by toggling the switch on (pink).

![](/assets/img/undefined-jun-03-2021-01-51-56-74-pm-e3db86b6.webp)

This will then reveal further options. [Editing interests](#ED) and [enabling social media profiles](#sm)

![](/assets/img/undefined-jun-03-2021-01-52-53-62-pm-7be3da72.webp)

#### Editing interests

This step is optional. Enter an interest and click add. Continue in this way adding each interest individually (up to 50).

![](/assets/img/undefined-jun-03-2021-01-56-37-74-pm-ea9f238c.webp)

When delegates create their name badges, they can select as many as they require.

![](/assets/img/undefined-jun-03-2021-01-58-53-29-pm-671bf5e2.webp)

#### Social media profiles

Check all that apply. Changes are saved automatically.

![](/assets/img/undefined-jun-03-2021-01-59-48-77-pm-4d69b414.webp)

Delegates can add their profiles as below. NB. This is optional

![](/assets/img/undefined-jun-03-2021-02-01-11-86-pm-c216399d.webp)
