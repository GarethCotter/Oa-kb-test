# Creating a session

## After you have set up your online program settings, you can create a session.

The guidance below is for event administrators/ organisers. If you are an end user (eg. submitter, reviewer, delegate etc), please click [here](https://oxfordabstracts.com/resources/contact-support/).

NB: Go to **[Event dashboard](/01-getting-started/event-dashboard) → Conference →** **Program** ➞ **Builder**

You can create a session by clicking on the default session or, to add a new session, click **Add Session**button.

NB: The default session will only show if you have added a start date in [Event details](/01-getting-started/event-details).

.![](/assets/img/undefined-mar-01-2021-04-03-30-57-pm-359dcd3a.webp)

The session control panel will open up.

|  |  |
| --- | --- |
|  | 1 [Session name](#SES)  2) [Dates](#DAT)  3) [Add presentation link](#PRESS)  4) [Description](#DES)  5) [Column](#CLTP)  6) [Locations](#CLTP)  7) [Add tracks](#CLTP)  8) [Presentation type](#CLTP)  9) [Session chairs](#SES)  10) [Sponsors](/08-conference-platform/professional-conference-sponsors)  11) [Admin notes](#Admin)  12) Mark as a recommended session  13) [Attach symposia](/08-conference-platform/attaching-content-to-sessions) |

NB: When you hover on some of these details, you will notice a settings icon. Click on this to access the [Configuration settings](/08-conference-platform/setting-up-your-program-configuration).

![](/assets/img/undefined-mar-01-2021-04-39-06-61-pm-422cbf5c.webp)

**1) Session name**

Click in the field to add a name.

2) **Dates**

Click on **Start time, End Time** and **Date** to enter your choices

NB - the dates are automatically pulled from the event details.

![](/assets/img/undefined-mar-01-2021-04-32-17-00-pm-4837508e.webp)

**3) Presentation link**

This field is for entering a video link.

Simply add the text you want to appear on the button, and the link itself.

![](/assets/img/undefined-dec-22-2021-11-53-11-89-am-ec24c37c.webp)

**4) Description**

Click to add a description.

**![](/assets/img/undefined-mar-01-2021-04-35-16-64-pm-8816b12b.webp)**

**5) Column 6**) Locations, 7) Tracks and 8) Presentation types**

Make your choices from the dropdown menu. In all these cases, choose just one.

**![](/assets/img/undefined-mar-01-2021-04-37-31-99-pm-625aa950.webp)**

**9) Session chairs**

Make your choices - you can click on as many as you require.

**![](/assets/img/undefined-mar-01-2021-04-48-11-14-pm-59fecc41.webp)**

**11) Admin notes**

You can add notes here - these will be seen by any other admin.

**![](/assets/img/undefined-dec-22-2021-12-24-29-03-pm-3b55c0bf.webp)**

Ensure you click the **SAVE** button when you have made your changes.

![](/assets/img/oxfordabstracts-freshdesk-comsupportsolutionsarticles8000081-6caea76c.gif)
