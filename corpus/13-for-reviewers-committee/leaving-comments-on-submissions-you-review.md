# Leaving comments on submissions you review

## In this article we will take you through how to leave in-line comments on any submissions that you're reviewing.

NB: The below guidance is for reviewers only.

If you are a submitter, see [Viewing comments left by reviewers](/12-for-submitters/viewing-comments-left-by-reviewers).

**How to leave comments on a submission:**

Once you've logged in and have selected "Start Reviewing", you'll know that the comments feature has been enabled if you see "Comments enabled". If you don't see this, this means the event administrator has not enabled this feature.

![](/assets/img/screenshot-2022-04-11-at-12-21-45-png-e44c6407.webp)

**How to leave a comment on text or an image:**

1. Highlight the text or image you wish to leave a comment on

2. Click on the blue comment button that appears next to the highlighted section

![](/assets/img/screenshot-2022-05-18-at-10-07-52-png-f58b2f04.webp)

3. A comment box will appear where you can type your comment

4. Click **comment** or hit return to save the comment

5. Your comment will appear under 'In-line Comments' section

![](/assets/img/screenshot-2022-04-11-at-12-29-46-png-cba93640.webp)

**How to edit or delete a comment:**

There are two ways to do this:

1. Select the highlighted text you have already left a comment on. This will open up the comment box and allow you to edit or delete the comment.

2. Click on the 3 dots on the comment, and select **Edit** or 'Delete'.

![](/assets/img/screenshot-2022-04-11-at-13-44-26-png-3c9c638c.webp)

**How to compare previous submissions with new submissions:**

In a scenario whereby the author has made changes to the submission after you originally reviewed it.

1.  Go onto the submission

2. If changes have been made, you will see "View earlier submission"

3. Select **View earlier submission**

4. You will see earlier submission and the latest submission side-by-side

![](/assets/img/screenshot-2022-04-11-at-15-02-43-png-920d1ad2.webp)

5. If there are multiple earlier submissions, then choose the correct submission from the dropdown

![](/assets/img/screenshot-2022-04-11-at-15-19-32-png-0fa4046f.webp)

If you encounter any problems with in-line comments, then please get in touch with our support team: support@oxfordabstracts.com for further assistance.
