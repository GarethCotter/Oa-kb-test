# Application programming interface (API)

## Application Programming Interface (API) allows applications to communicate with one another. This means you can extract/share data from your event with third party applications or vice versa.

The guidance below is for event administrators/ organisers. If you are an end user (eg. submitter, reviewer, delegate etc), please click [here](https://oxfordabstracts.com/resources/contact-support/).

In order to generate an API code and access the API documentation; Account Administrators and Event You must first set up an API user by either:

a) Go to the **[Event dashboard](/01-getting-started/event-dashboard.html) → Event Setup → Event Details**

Scroll to **More options** at the bottom.

Then toggle to Enable API.

![](/assets/img/undefined-aug-23-2021-09-29-40-84-am-cc1049f9.webp)

b) Or you can go tothe **[Event dashboard](/01-getting-started/event-dashboard.html) → Users,**  then click on the **API USERS** tab.

![](/assets/img/s3-amazonaws-comcdn-freshdesk-comdatahelpdeskattachmentsprod-9fb799cb.webp)

You can add an optional invitation message, then add the email address(es) of anyone you wish to invite to be an API user. Click **INVITE API USERS** to send the invitation.

To use the API you will need to go to   
https://app.oxfordabstracts.com/graphql-docs

Where you will see the following:

![](/assets/img/image-png-may-13-2022-07-43-40-12-am-0e4b12fe.webp)

From here you can generate an API key

![](/assets/img/image-png-may-13-2022-07-44-09-55-am-8b4aa0d7.webp)

Then click on **Generate**

![](/assets/img/s3-amazonaws-comcdn-freshdesk-comdatahelpdeskattachmentsprod-26647cab.webp)

The key is a unique identifier that the application should communicate with your event to connect with it.

![](/assets/img/image-png-may-13-2022-07-45-22-55-am-3220705d.webp)

Go back to https://app.oxfordabstracts.com/graphql-docs to access the API functions.

To see an overview of the function of the API, please watch the following video - [How the API functions.](https://www.loom.com/share/ee0a790ed62f425c833ac50df4abc1b0)
