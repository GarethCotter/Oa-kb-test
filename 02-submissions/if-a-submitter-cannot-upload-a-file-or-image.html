If a submitter can't upload a file or image

More often than not the setting is at your end rather than a fault at theirs, and these five checks find it. Take a screenshot of the error from the submitter before you start — it usually names the cause.#

1. Is the file bigger than the limit you set?#

File upload questions start with a 10MB limit, which you can raise to 500MB. Ten megabytes is fine for a PDF and nowhere near enough for video or a detailed poster. Check the limit on the question, raise it if you need to, and put the limit in the question text so submitters know before they try. See Submission question types.

2. Does the question accept that kind of file at all?#

A file upload question can be restricted to PDFs only. If somebody is trying to attach a Word document or an MP4 to a PDF-only question, it will be refused.

The same applies to images inside a text answer: a submitter cannot paste a graph or figure into an abstract box unless that question is configured to allow images. This is a common one — the submitter is told images are acceptable, tries, and cannot. Turn images on for the question, or add a separate image upload question.

3. Is the form actually open to them?#

This catches people out constantly. If your form is open for incomplete submissions only, anybody whose submission is already complete cannot edit it — so they cannot add a file to it either.

It comes up most when you ask accepted submitters to add a poster or presentation after the fact. Either reopen the form for edits, or collect the poster in a second stage; see Opening and closing submissions (deadlines) and Setting up a multi-stage event.

4. Have they tried another browser?#

Ask them to try a private or incognito window, or a different browser, and to make sure theirs is up to date. An out-of-date Safari in particular accounts for a fair number of uploads that fail silently.

5. Is their network blocking us?#

If they see Network Failure, or the page will not load at all, their institution is almost certainly blocking the site — see Fixing a "network failure" error. Their IT department can allow it, or they can try from home or a phone network.

If none of that explains it#

Occasionally an upload genuinely half-completes and the file is stored broken — the symptom is that nobody, including you, can open it. In that case ask the submitter to upload it again, and if it fails a second time contact support with the submission number and the error they see.
